# Day 01: Linux and Docker Fundamentals

## Learning objectives

- Understand Linux filesystem navigation and management.
- Manage users, groups and file permissions.
- Inspect processes and system services.
- Read system logs using journalctl.
- Build and run a Docker image.
- Understand container ports and basic container execution.
