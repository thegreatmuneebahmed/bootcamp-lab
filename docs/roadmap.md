This document tracks the planned learning progression.

| Day | Focus | Status |
|---|---|---|
| 01 | Linux fundamentals and Docker basics | Completed |
| 02 | Docker Compose, storage and networking | Completed |
| 03 | Multi-container applications and Redis | Planned |
| 04 | Linux networking and troubleshooting | Planned |
| 05 | CI/CD with GitHub Actions | Planned |
| 06 | Infrastructure as Code with Terraform | Planned |
| 07 | Deployment, monitoring and final project | Planned |

## Completion standard

A day is completed only when:

1. Concepts have been taught and understood.
2. Practical exercises have been executed.
3. Results have been verified.
4. Relevant files and documentation exist.
5. Changes have been committed and pushed.
6. No unresolved critical errors remain.

A topic being introduced does not mean the entire day is complete.
